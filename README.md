# OrangeHRM Login Automation Framework

Automated login validation framework for OrangeHRM using Selenium WebDriver, TestNG, Maven, and Page Object Model. Covers valid and invalid login scenarios with dashboard validation, external configuration, and screenshot capture for failures.

## Tech Stack

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)

## Framework Structure

src/main/java

* pages
* utilities

src/test/java

* tests

## Features

* Valid and invalid login validation
* Dashboard page verification
* External configuration using properties file
* Screenshot capture on failure

## Execution

Run using TestNG or Maven:

mvn test
